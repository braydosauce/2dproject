Description:
A 2d sword fighting minigame against a never ending wave of monsters you must defeat in order to get the highest score
possible before you die. Features Knockback, collision detection, enemy ai behavior, health tracking using object 
oriented scriping, dynamic monster spawing mechanics, and player combat loops.

Controls:
W = Up
S = Down
A = Left 
D = Right

Dash: 
Double click any direction key to dash in that direction

Attack:
Right click
